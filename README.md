# Stranger Mingle

One of India's safest community platforms for making real, platonic friendships through organized weekend meetups, an exclusive members platform, and periodic online intercity events.

Currently active across **Pune, Mumbai, Bengaluru, Hyderabad, and Delhi**.

---

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Technology Stack

- **Framework**: [Next.js 15+](https://nextjs.org) (App Router)
- **Database & Auth**: [Supabase](https://supabase.com)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Payments**: Razorpay

## 🔐 Safety & Community

Stranger Mingle is built on trust. We enforce a **Zero Harassment Policy** and all members are verified before joining events or the members platform.
